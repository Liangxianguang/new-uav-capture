# V20：响应模型不是全无信号，而是弱响应误报抵消了强响应收益

本轮不训练、不晋级，也不改原 GRU + distributed-delayed DN-MPC + local
CBF。只对已经看过的 V19 训练/开发数据作事后诊断，不能当成独立新验证。
V19 的响应/决策失败结论不变，增强控制器仍关闭，保留 holdout 未读取。

## 证据来源与统计口径

从已发布 V19 归档重新校验 manifest、两轮训练权重/优化器/RNG/历史、
原252公开帧、延迟计划、原完整成本与全部门，再加载全部9个最终模型。
每个模型都在24训练组/8开发组上重新推理；开发预测必须逐位等于发布结果。
没有新增优化器，没有最佳种子/epoch/窗口选择，也没有阈值搜索。

配对支持严格为有效候选 AND 有效anchor AND 原始命令不同。锚点和终止后
padding排除。开发共18,083个配对点，训练54,912个；同组镜像不分开。
验收响应距离按组内所有有效点平均，再组等权；同时报告call-balanced
坐标MSE，区分原训练损失和验收指标的两种权重。坐标MSE诊断从原标签
重新算浮点统计，不声称与训练的float32/minibatch损失历史逐位相等。

分箱上限固定为1e-10m/1cm/5cm/20cm，所有时域offset1–8均报告。
这些是真值标签分箱，不是控制器运行时可知的分组，不能拿真值来开关响应。
条件均值明示有支持的组数；误差贡献始终以全部原组为分母，空箱贡献为0，
所以五箱贡献可加回整体模型减零响应的误差差值。

## 1. 六个响应模型的平方误差都改善，但向量误差并不稳定改善

零响应开发向量误差0.084831m、坐标MSE0.014343m²；训练向量误差0.095577m。
原开发门是向量误差中位数≤零响应的95%，而不是MSE改善。

| 模型/seed | 训练向量误差/m | 开发向量误差/m | 开发坐标MSE/m² |
| --- | ---: | ---: | ---: |
| raw 989101 | 0.052553 | 0.078856 | 0.009327 |
| raw 989102 | 0.050946 | 0.085681 | 0.010626 |
| raw 989103 | 0.051050 | 0.090403 | 0.012300 |
| 中介 989101 | 0.055647 | 0.084736 | 0.009928 |
| 中介 989102 | 0.051833 | 0.087103 | 0.010931 |
| 中介 989103 | 0.053100 | 0.088364 | 0.011185 |

六个模型的训练向量误差均比零响应好，但开发差距明显。不能只说“没训练够”，
也不能据此单独断定过拟合：公开可观测性和场景差异还没有被排除。
模型偏好降低少量大误差的平方损失，与降低大量小误差的平均向量距离不同。
这是一项真实发现，不是改门理由；全部三个种子仍报告，不挑989101晋级。

## 2. 约70%开发点是弱响应，六个模型都在这些点上增加误差

开发组等权响应幅度分布：数值零23.542%、(0,1cm]27.094%、
(1,5cm]19.417%、(5,20cm]17.761%、>20cm12.185%。
前三箱合计70.054%的点不超过5cm；全部五箱在8个开发组都有支持。

下面是对全体开发指标的**可加误差贡献**。正数表示模型比零响应更差，
负数表示模型更好。弱响应不是通过筛选样本改善总体得分，而是定位失败来源。

| 模型/seed | ≤5cm误差贡献/m | (5,20cm]贡献/m | >20cm贡献/m | 总误差变化/m |
| --- | ---: | ---: | ---: | ---: |
| raw 989101 | +0.015174 | -0.000531 | -0.020619 | -0.005975 |
| raw 989102 | +0.018288 | +0.002298 | -0.019736 | +0.000850 |
| raw 989103 | +0.022370 | +0.004518 | -0.021315 | +0.005572 |
| 中介 989101 | +0.019498 | +0.002428 | -0.022022 | -0.000096 |
| 中介 989102 | +0.022363 | +0.003485 | -0.023576 | +0.002272 |
| 中介 989103 | +0.021936 | +0.004549 | -0.022952 | +0.003533 |

>20cm箱的真响应条件平均为0.470885m；raw误差0.305901/0.318476/0.310962m，
中介0.293033/0.285206/0.289104m。六个模型均有强响应学习信号，但这个
标签条件下的收益不能证明运行时能识别这些点或提升闭环围捕。

在真实数值零的点上，六个模型仍预测平均约1.2–1.6cm的响应，
其中约4.36–7.27%预测超过5cm；在真实(0,1cm]点上，约15.22–19.90%
预测超过5cm。抑制弱响应误报值得优先验证，不能简单切除弱响应点。

## 3. 时域分解支持短时误报，但不支持挑后半窗口重新验收

全部六个响应配置在offset1–4的平均向量误差均高于零响应；较后offset
存在收益，但大小依种子而变。完整八步仍用于原门和成本；不能事后把前四步
屏蔽，也不能把开发后半窗口的改善说成模型整体通过。全部offset数字保存在
结构化诊断报告中。

## 4. 中介改善绝对命令，却几乎没有改善整体命令对比

冻结公开CBF中介在新几何分布开发数据上：

| 诊断量/m·s⁻¹ | 原proposed | 冻结公开中介 |
| --- | ---: | ---: |
| 观测到的绝对command误差，call/group等权 | 0.637933 | 0.340889 |
| 因果支持上的配对command delta误差，四agent平均 | 0.308680 | 0.307078 |
| 同支持本agent的配对command delta误差 | 0.532345 | 0.467028 |
| 数值零响应箱，四agent配对delta误差 | 0.105213 | 0.168734 |

训练集对应整体四agent delta为0.288679→0.291475m/s，未改善。
绝对command精度和动作对比精度不是同一个目标：共同误差可能抵消，独立估计
也可能引入额外对比误差。这解释了为什么仅把更准的中介command输入响应网络
并不保证响应更好；尚不能证明中介是唯一失败来源。

## 下一轮具体方向

优先验证**响应损失与验收向量距离一致**的训练，并保留配对MSE控制，
分别隔离损失几何和call/point权重的影响。仍用相同冻结共同运动、原GRU和
原DN-MPC/CBF，不把纯运动预测提升充当因果贡献。首先使用raw输入，避免
把尚未稳定改善对比的中介同时作为另一个改动。中介改进后续需要直接检验
配对command delta，而不只检验绝对command。

这是待检验方向，不是成功保证。下一轮必须另立协议和独立新组，不能继续
在本开发组上调损失、挑种子，再称为新验证。响应仍需优于零响应并通过
原完整成本决策门，之后才可做实际顺序候选、完整关闭/拒绝/失败回退、
保留holdout、原8Level及新场景增强闭环、安全和延迟验收。

结构化报告、两次完整诊断的重复证据和实现见 `experiments/cwm_v20/`；
