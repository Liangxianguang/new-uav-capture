# V46 streamed inventory integrity primitive

This is a low-level preparation for future complete independent activity-result replay. It is not a saved-development semantic auditor, policy replay entry, artifact certificate, model qualification, training result or deployment gate. V42/V45 and all running scientific sources are unchanged.

`experiments/cwm_v46/manifest_reader.py` reads every member of the sorted V42/V45 JSON evidence inventory without constructing the full Python dictionary. Each token is bounded to 1 MiB by default, read chunks are 64 KiB, and an individual record/name is held at a time. These settings do not bound the entire process memory. Full consumption is mandatory: partial iterator consumption does not check closing/trailing JSON or later records.

The parser rejects malformed/truncated JSON, duplicate metadata fields, duplicate/unsorted member names, unsafe paths, unexpected record fields, Boolean/fractional/negative lengths, nonfinite values, invalid SHA256 text and trailing content. `verify_members` requires the fixed manifest inside the evidence root, matches all records against a caller-provided independently derived complete sorted expected iterator, opens/hashes every regular member, and rechecks the inventory hash after verification. It returns only a count, never qualification flags or permissions.

The caller must derive membership from the complete pinned scene/method populations, episode/step evidence, every trajectory/command/event and all event array/context references. Using the same untrusted manifest as its own expectation only verifies file integrity and cannot detect scientific omissions. This primitive neither derives that semantic inventory nor verifies source publication, model/certificate qualification, per-step support, cross-member case aliases, statistics, physics, actual native execution, native replay, active faults, archive transport or holdout eligibility. Files are checked at their individual access times; a later mutation of an already-checked member is not ruled out. The complete future auditor/replayer must still provide source/input rechecks and the remaining scientific validations.

Tests on 2026-10-11: 37 passed in 0.88 seconds, actual exit 0. Synthetic 512-member fixtures exercise chunk sizes 1/2/3/7/64/65536 and Unicode escaping. A 1024-member fixture exceeds the per-token bound in aggregate. Negative fixtures cover malformed/duplicate/nonfinite/truncated content, membership omissions/additions, altered/missing files, altered expected digests, wrong manifest location and manifest mutation during verification. Interoperation with the actual V45 writer is tested. These are not million-member performance measurements or qualified native results. No model, scene generator, optimizer, holdout or native policy was launched.

The enhancement remains disabled. Complete V34 audit, both fixed V36 training runs, V37 all18 reload and V38 independent science archive replay precede any qualified native development. Complete paired native development, genuine active-model fault tests, full independent activity replay/archive and the single sealed holdout remain required before promotion. This primitive substitutes for none of them.

## Complete paired step-support primitive

`paired_step_support.py` additionally validates the exact frozen V39 development plan and unchanged V30 row rules, then requires the native per-scene eight-method rotation and all assigned episode identities. `index_both` refuses a single cohort and indexes both original 1280 x 8 and fresh 64 x 8 method-episode populations. It reads all step JSONL lines, retaining byte offsets/counts per block rather than all step dictionaries. Caller-owned episode rows and their timing lists are still in memory.

Every block must have contiguous integer steps 1 through the episode's exact control-step count, correct cohort/episode/method identity, step timings matching every saved native/end-to-end sample, and matching complete solver failure-step/total counts. Boolean identities/times/counters, fractional/negative counters, duplicate JSON keys, missing/reordered/extra blocks or steps are refused. Input step-file hashes are rechecked after indexing. This returns offset indexes only, not permission or a native execution certificate.

Updated V46 regression: 60 tests passed in 18.51 seconds, actual exit 0. This includes a complete synthetic 10,752-method-episode fixture with 10,754 total one/two-step records, read-back validation of every returned byte range, and negative population/rotation/timing/failure-support tests. The fixture is not a physical simulation and does not prove native capture or latency. No real enhanced results exist to audit yet. The helper still does not verify complete physical scenes, outcome/trajectory agreement, commands, model reconstruction, public candidate/context semantics, source publication or all diagnostic values against independently executed policies. These checks remain required in the future complete auditor/replayer; passing step support cannot replace them.

Combined V39/V42/V43/V44/V45/V46 regression: 205 passed in 26.65 seconds, actual exit 0. Existing scientific sources were not edited.
