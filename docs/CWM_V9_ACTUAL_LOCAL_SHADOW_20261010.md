# 实际局部候选影子验证：找到研究价值，但旧模型仍不替换

日期：2026-10-10。阶段：V9 影子适配与原策略回退验证完成；没有
新增训练或触碰 holdout，没有启用增强控制，也没有证明围捕成功率
提高。原 GRU + distributed-delayed DN-MPC + 经验型 local CBF 保留。

## 为什么本轮改变了下一步方向

V8 的八个固定压力/制动探针里，即使真实响应也不改变选择；这个
结论没有覆盖原 DN-MPC 的预测依赖型局部候选生成。本轮复制实际
`_select_local_sequence` 调用与当时收到的延迟消息，在原计划返回
后使用原候选生成器扩展候选，再做完整原局部评分与克隆分支。

结果出现共同运动预测与真实动作响应的诊断价值，因此现在有证据
支持下一阶段研究“共同运动校准 + 动作响应”，而不是因为 ADE
改善就默认需要校准头。然而现有 V7 两个学习响应模型仍没有额外
正收益，不能因此上线，也不能覆盖 V7 未通过的普通模型对照门。

## 做了什么，没有做什么

使用已检查过的 V7 开发集8组/16场景，不是独立测试集或原八个
Level。每个公开 snapshot 只采集每个 agent 的第一次实际局部调用，
保持原调用顺序、原候选、原 selected score 和收到的 peer plans。
实际80个 snapshot 共320个调用；128个因缺少完整三队友消息而
跳过，192个有完整延迟上下文。没有拿最终集中式联合计划补齐
局部缺少的消息，原通信、迭代与目标权重没有改变。

共同的候选库按固定顺序组成：原局部候选、原生成器在常速度预测
上的候选、在普通/结构化模型对各原候选的预测上的一轮候选。
精确去重，保留原顺序；没有迭代新模型至收敛，没有用 truth 生成
候选。每个完整上下文候选数2–8，均值2.96875，共570个分支。

模型使用原公开8×252历史与已经计算的冻结 GRU、own 当前公开
状态和收到的三队友延迟状态。参考联合命令由实际选中的 own
序列和收到的三队友序列组成。延迟相对状态与局部参考命令均与
V7 的训练上下文有所不同，是需重新收集数据处理的迁移误差。
原公开历史本身沿用原预测器的共享输入，不声称全新严格本地
观测架构。没有私有目标真值、分支符号或未来路由输入。
模型预测在这里是 raw 离线诊断容器，没有动力学投影或安全认证。
结构化网络是配对干预响应模型，尚未建立可识别 SCM；未来共同
运动校准头本身也不能当作因果创新的证据。

公共预测与候选库先冻结，然后才在当前环境的克隆中执行8步固定
联合命令，使用原 CBF 与按步共同 sensor/execution 噪声，终止
即停止。真实未来只用于诊断标签。192个参考分支独立重复相同，
原实际环境状态与 RNG 不受影响。570个候选分支的末状态为363
个仍 running、207个 safe_capture；没有记录到目标无效或防守者
安全终止，但这只是有限、受截断的分支测试，不是安全证明。

61个调用因至少一个候选/参考分支支持不足8步而不能使用 truth
排名。所有方法共同保留131个完整调用；不补终止后的标签。
完整支持也不是未来策略安全证书。真实局部评分仍使用冻结的
延迟 peer positions/sequences，与克隆环境当前真实起点不同；
这是原局部估计与假设联合分支的诊断比较，不是真实回报。

## 同一扩展候选库上的诊断结果

gain 为 action-specific truth 下的原局部目标 regret 改善，按8组
等权。单位是原诊断成本，不是成功率、距离或累计实际回报。

| 信息条件 | 对同库 GRU 改变选择 | 对同库 GRU 的组等权 gain |
| --- | ---: | ---: |
| 同库原 GRU | 0/131 | 0 |
| 普通学习响应 | 6/131 | -0.081189 |
| 结构化学习响应 | 9/131 | -0.092071 |
| 常速度 | 85/131 | +1.317596 |
| GRU + 真实响应 | 9/131 | +0.097896 |
| 真实参考运动，不加响应 | 84/131 | +1.337447 |
| 完整 action-specific truth | 89/131 | +1.578584 |

普通/结构化学习响应的描述性95%按组区间分别
[-0.238983,0.030195]、[-0.232609,0.015592]。真实参考运动的
gain 区间[0.990480,1.696404]，8组均为正。给定真实参考运动，
再补全真实动作响应改变7个选择，额外 gain +0.241137，区间
[0.090841,0.391682]，6组为正。两项探索性 research signal
成立，但不是未触碰 holdout 的推断，也不授予部署资格。

给定真实参考运动再加普通/结构化学习响应，额外 gain 分别为
-0.003956、-0.010897，仍为负。说明真实机制有价值，但目前模型
没有充分恢复这种价值。GRU+真实响应的小正均值区间跨零，不能
把它说成稳定收益。常速度在本扩展库上有效，不与 V8 两次更差
选择矛盾：候选库、局部目标、支持人口均不同。

另一个必须区分的因素是候选生成。对照实际原局部选择，仅使用
原 GRU 在这个扩展库重新选，就改变44个选择，gain +1.453603。
因此普通/结构化模型相对实际原选择的 +1.372414/+1.361532
不能当成“因果响应收益”；相同库中原 GRU 已经做得更好。
扩库效果与预测效果必须分别保留对照。

## 保留和回退验证

五种独立过程模式：shadow 两次、默认 off、注入可选 checkpoint
加载失败、实际 V7 资格门未通过。每种16个场景全部存储的轨迹
字段与 V7 原策略 dtype/shape/raw bytes 相同，六项结果字段一致。
两次 shadow 调用记录与公开上下文字节相同，全部预测/分支数组
字节相同。这是80次原策略重放，不是80次增强控制成功。

off 不读取可选权重、不调用可选模型；失败模式每个 provider 只
尝试加载一次后保持失效；资格门阻止加载。provider 的预测失败
也会锁定回退，单测覆盖格式、非有限输出和参考轨迹字节被改变。
可选模型构造保留原 Torch RNG，不额外调用原 GRU。参考响应
严格为零，但完整模型控制入口的启用尚未实现/验证，不能把这个
性质当作整个增强策略的回退证明。

验证器用安全 JSON 公共上下文与冻结源码重建原局部候选、局部
评分与选择；重载公开模型后重新生成同一候选库，预测数组字节
一致；重新计算九类完整成本、rank/regret、支持和按组统计。
它核验真实 target-wall/boundary 与终止掩码，不加载保存的 pickle。
克隆目标动力学的独立复现来自两次完整运行；发布验证器不声称
仅凭公共 JSON 就能重放含私有目标状态的完整克隆动力学。

90项 V1–V9 专项测试通过，包括伪造成本而保持报告、改动延迟
上下文并更新摘要、伪造物理掩码并更新摘要、资格门覆盖与 off
模式误加载的拒绝。所有代码仅在独立研究分支，原 dirty checkout
没有修改，原训练进程没有停止。没有改变 CBF 裕度或旧权重。

## 下一阶段训练任务

现在已有决策证据，可以固定新训练假设：分开学习“局部参考
命令下的共同运动校准”和“改变 own 命令产生的配对响应”，
都作为可关闭的 GRU 外部增强，不更新原 GRU。

首先按同一实际延迟上下文/局部候选生成器收集训练组，不继续
仅用全局最终计划和压力探针训练；以 group 为单位固定划分，
原保留 holdout 继续不触碰。模型训练只读取公开输入，克隆 truth
仍仅为监督。保持普通/结构化参数量和预算匹配，保留常速度、
运动校准但零响应，以及仅扩库原 GRU 的消融。

验收不能只看 ADE：要分别检查同库预测收益、各模型自生成候选
的收益、响应对共同运动头的增量，以及未知消息回退。训练完成
后再进行固定开发评估、未触碰 holdout、完整可选入口 off/failure
等价性、原8个 Level 回归、新场景转移、安全和实时延迟资格检查。
本轮计算在原 plan 返回后运行，不能据此宣称满足100ms在线预算。
所有学习/诊断门继续有效，目标仍未完成。
