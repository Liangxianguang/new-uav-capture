# 围绕真实失败选择下一步，而不是增加“因果”标签

这是研究方向备选记录，不是新训练协议、已有效模型或创新性文献结论。
依据是已经检查的V21/V22/V23结果；原控制器、权重、安全合同和holdout
保留。采用brainstorming-research-ideas的问题优先、失败边界和组件拆分
框架，把“没有可选动作”“响应排序不准”“预测运动偏差”分开。

## 一句话问题与当前边界

当前世界模型平均响应误差下降，但没有稳定降低所选动作的真实原成本。
实际原候选多数只有一条不同轨迹，扩展候选的排序又缺乏开发泛化；模型
应既有可改善的公开候选空间，又能在不依赖真值的前提下可靠选择动作。
受益者是需要保留现有高质量DN-MPC+CBF、验证可关闭增强的使用者。

## 保留全部备选及筛选理由

| 方向 | 对应失败/机制 | 当前处置 |
| --- | --- | --- |
| 公开候选多样性与顺序重评分 | 单候选不能通过重评分受益；需要打通决策接口 | 优先诊断，后续必须对照候选本身收益 |
| 成对/列表式决策排序监督，保留响应轨迹输出 | 均值L2及效应L1不保证关键排序正确 | 候选训练假设，不能保证有效 |
| 镜像/旋转等变响应表示 | train/dev泛化、镜像场景关系 | 候选结构假设，先检验对称性是否被观测破坏 |
| 目标反应分支/多模态预测 | 均值响应可能抹平不同逃逸反应 | 需先确认分支误差证据，不直接堆组件 |
| 公开模型分歧驱动的成对数据采集 | 固定探针可能没覆盖关键动作比较 | 可研究；不能用私有未来选择在线探针 |
| 预测不确定性与拒绝回退 | 错误反事实可能伤害动作选择 | 接口与可信校准都要验收；不能只靠阈值救失败门 |
| 公共运动校准增强 | CV起点校准改善了ADE | 单独标注运动收益，不能冒充因果贡献 |
| 继续增加epoch/种子扫描 | 同类固定预算训练已反复失败 | 不优先，拒绝事后挑最好seed |
| 加大网络/混合多个中介 | 没有可归因的排序收益证据 | 暂不采用；已有中介失败需要保留 |
| 加长原MPC horizon或改安全margin | 可能改变响应信号与选择 | 不采用此方式推进本阶段，会改变冻结基线合同 |
| 新难场景/更强反应分布 | 基线在本批64回合达到成功率天花板 | 允许新场景，但不得事后挑场景取代原8Level验收 |

筛选出的前三个研究切入点是候选接口、决策排序监督、几何等变响应。
这不是已经选定并启动的新模型；先用V24定位候选退化的公开原因，再
结合失败归档选择可证伪的训练设计，保留其他方向及否定证据。

## 优先的小型诊断与之后三项必要实验

V24只重建公开候选：完整V23数据独立审计后，用独立代数重建所有原
指令字节，分离interceptor的perimeter不变性和限速导致的退化。它不
增加候选、执行无速度限值动作、训练或使用holdout，也不是新验证集。

之后的实验必须分开回答：

1. 同一公开候选库上，响应模型相对冻结运动/原GRU/CV能否改善选择。
2. 同一原评分器下，增加公开候选本身能否改善闭环，而不是冒充世界模型收益。
3. 固定候选与配对模型上，新排序/表示是否在新训练-开发组和最终未触碰
   holdout泛化，并通过原8Level及新场景捕获、安全与延迟验收。

最强反对意见是“候选变好而模型没有贡献”。回答不能靠解释，而必须
靠相同候选库上的配对消融及真实闭环测量。新训练要先另立公开协议和
固定预算/主实验/门槛，不能借V24后验结果放宽V23失败资格。

原模型的完整入口关闭/拒绝/异常回退等价还必须实测，不能因为原胶囊
hash不变就宣称所有增强路径已完全复现。整个训练与验证目标仍在进行。
