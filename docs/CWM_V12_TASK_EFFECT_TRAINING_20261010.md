## 固定训练，而非预测低成本奖励

沿用V10新的可选两头架构，原GRU不进入优化器。普通/结构化总
参数32736/32960；仅运动响应头冻结，可训练参数31176。3种子
974101–974103，80固定epoch，Adam lr.001、batch32、clip1。
运动/响应两头各2.5m坐标残差限幅，不是动力学或安全证书。
每组逆调用数的minibatch加权，同V10；仅用新训练历史归一化。

五配置：独立仅运动、普通MSE、结构化MSE、普通任务、结构化任务。
MSE/任务配对相同架构、初始化与采样顺序。物理MSE、残差正则
不变；任务版本额外使用V11完整原MPC成本的配对效应误差，权重1。
预测效应与真实效应都放在同一真实参考轨迹上，标签detach，
参考梯度平方范数归一化，完整有效调用才进入辅助项。没有
最小化“模型预测成本”的奖励，也没有label-based resampling。
缓存的任务标签/损失/梯度与V11已核对实现完全一致。

关闭整个可选模块才保留原预测；参考命令响应为零并不要求启用
运动校准时参考预测等于原GRU。当前训练及验收仍是offline，
没有用这句话冒充实际入口关闭/失效回退的增强控制器证明。

## 新开发集结果：运动进步不等于因果响应进步

以下是8组等权、同支持的全分支ADE/非参考配对响应误差，单位m。
三个seed取中位，不选择最优seed或epoch。全部seed的完整结果
见归档及`experiments/cwm_v12/reports/training_summary.json`。

| 模型 | 中位ADE | 中位响应误差 | 中位归一化成本效应loss |
| --- | ---: | ---: | ---: |
| 原GRU/零响应 | 0.580207 | 0.016003 | — |
| 常速度/零响应 | 0.360198 | 0.016003 | — |
| 独立仅运动 | 0.250578 | 0.016003 | 0.00193789 |
| 普通MSE | 0.252603 | 0.019304 | 0.00178131 |
| 结构化MSE | 0.256338 | 0.018752 | 0.00172773 |
| 普通任务 | 0.255508 | 0.021847 | 0.00203092 |
| 结构化任务 | 0.255519 | 0.021360 | 0.00198984 |

两个任务模型中位ADE比原GRU约降低55.96%、比CV降低29.06%，
运动门通过。但所有任务seed响应误差都高于零响应；两个任务
模型的中位任务效应loss也比同架构MSE更大，没有满足降低5%的门。
因此额外监督在此次固定设计和预算下没有改善响应，不应继续
把运动校准收益算成因果世界模型成功。

## 同冻结局部库决策：响应增量为负

用原完整局部成本引擎重新评分129个共同完整开发调用，不使用
可微训练评分替代排名，也不把truth或未来信息送入网络。
固定按ADE取中位seed：仅运动974101、普通MSE974101、结构化MSE
974102、普通任务974103、结构化任务974102。

| 同库模型 | 组等权诊断regret |
| --- | ---: |
| 原GRU | 1.315334 |
| 常速度 | 0.034406 |
| 独立仅运动 | 0.065035 |
| 普通MSE | 0.066868 |
| 结构化MSE | 0.139145 |
| 普通任务 | 0.146548 |
| 结构化任务 | 0.106165 |

这是离线诊断成本，不是实际捕获回报。普通任务相对自己的运动
分量，gain=-0.107865，描述性95%组区间[-0.221318,-0.025527]；
结构化gain=-0.017323，区间[-0.057050,0.015843]。相对CV、独立
仅运动也没有严格正下界，全部决策门失败。运动ADE比CV小仍
不能保证局部选择更好。使用同库GRU控制，避免把候选库扩展
本身的收益归因于学习模型；没有用新模型自生成候选库。

本次分开验收普通任务与结构化任务，不要求以图池化优势代替
因果响应 usefulness。两个架构同样接受干预标签，图结构本身
不证明识别了可迁移SCM。本轮结果更明确地否定了“加一个任务
loss就能解决”的假设，但不是证明所有因果建模方向不可行。
