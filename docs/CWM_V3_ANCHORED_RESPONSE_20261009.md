# 冻结原GRU的受限响应残差诊断

日期：2026-10-09。结论：**仍无有效因果增益证据，NO-GO，继续使用原DN-MPC + local CBF**。
不是正式新鲜泛化测试，不授权增强控制，不改变V2数据门槛未通过的结论。

## 本轮改动

原GRU权重及其输出不训练、不替换。新网络只拟合相对原规划的配对动作响应：
`prediction = frozen_backbone + bounded(f(candidate) - f(original_plan))`。
最终层零初始化，原规划作为候选时残差强制为零并直接返回原预测；连负零也保留字节。
残差逐坐标上限0.05m，3D范数最多sqrt(3)*0.05m。它不是动力学可行性或安全证书。
目前只用于离线诊断及shadow，从未选择或执行增强动作。

普通和结构化网络都输入相同的公共历史、相对状态、提议/原规划动作及冻结预测。
结构化网络共享逐机压力节点并聚合；这只是待验证的结构先验，不是已识别SCM。
普通网络29,752参数，结构化网络27,928参数，差异小于10%。

## 训练协议与限制

复用V2归档的12个原train组、51个窗口，没有增加S4或改变原目标规则。
每种场景的4个组按冻结种子930910分为2训练、1校准、1开发验证；27/12/12窗口。
源数据的响应汇总此前已查看，故不能把开发验证写成新鲜测试。
新协议在训练前冻结：三种子101/202/303，固定40epoch最终模型、单CPU线程、
同优化器与批量，损失只包含配对响应MSE及残差惩罚，没有按验证挑epoch。
只做小预算方法修正诊断，没有绕过V2门槛启动大训练或控制接入。

## 开发验证结果

| 方法 | 轨迹ADE（m） | 配对响应误差（m） |
| --- | ---: | ---: |
| 冻结原GRU、零响应 | 0.462922156 | 0.000001673 |
| 普通受限残差（三种子均值） | 0.462915709 | 0.000090631 |
| 结构化受限残差（三种子均值） | 0.462916464 | 0.000090476 |

结构化网络相比普通网络没有有意义的优势。轨迹ADE变化仅几微米，未作统计显著性
或控制收益声明；不能称为有效提升。响应误差仍弱于零响应，满8步有效配对对照的
真实响应为零。本轮没有新的捕获率、碰撞率或Level1–8覆盖结论。
这些窗口的恒速ADE为0.217364880m，仅为预测诊断，不等同恒速控制器优于原DN-MPC。

## 保护和复现检查

- 六个模型均可安全重载，预测及原规划主干字节一致，残差限幅检查通过。
- 独立重训的六个模型权重、开发/校准预测、每轮loss及指标一致。
- 四场历史场景（包含两个原失败）共351次shadow推理，零异常；原动作、目标及
  无人机轨迹字节和物理结果保持一致。它只证明旁路隔离，不是增强闭环安全。
- 本机额外推理耗时p50/p95/p99约3.181/4.942/5.996ms，不是实时保证。
- 新增8项单元测试覆盖零初始化、训练后原规划字节保护、压力节点置换、幅值上限、
  分组互斥及终止mask；原全256场基线复现结论仍见P0报告。
