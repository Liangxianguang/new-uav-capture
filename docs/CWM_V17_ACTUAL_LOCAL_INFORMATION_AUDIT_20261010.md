# V17：原局部候选有限，真实响应也没有改变这批原排序

日期2026-10-10。V15已训练但响应/决策门失败；V16新增几何也未
全面通过长时目标合法性门。本轮分解已发布V15数据，不采集新的
模型验证集、不训练或重新选择seed、不启用增强。协议先提交并
推送为`8af22e7`；所有描述性区间基于已看过的train/development，
不是新的泛化或holdout结论。

## 固定原模型与候选定义

原GRU+distributed-delayed DN-MPC+local CBF从冻结capsule恢复。
V15归档、V7候选来源、V14中介归档的SHA在协议固定。每次实际
调用的`actual_candidates`仅按原顺序、公开本机命令精确映射到
V15扩展union，保留首次出现的唯一动作。1,224个重复提议被披露，
不会把重复动作当作独立干预。候选映射不读取目标、终止和valid。

原代码`_local_candidate_sequences`在K=1时只保留一条不同预测
路径，再遍历外围尺度；截获机追踪target本身，不随外围尺度
变化，因此产生相同动作的重复候选。不能把这个条件性代码结构
诊断写成所有DN-MPC只有一种动作，或模型在所有场景都无价值。

全部1,536调用：训练1,152/24组，开发384/8组。实际唯一候选训练
900调用只有1个、252调用有2个；开发324调用只有1个、60调用有2个。
未来真值仅用于有限影子干预标签。V15三个固定ADE中位模型均
seed979101，重新公开推理时预测数组及完整开发指标与V15一致；
没有使用响应指标挑选seed。

## 真实响应与共同运动的原成本信息对照

每个完整候选集由原引擎重算完整K=1局部成本。条件包括原GRU、
CV、参考未来真值、GRU/CV加真实配对响应、每候选未来真值；开发
再加V15三个冻结模型、各自运动分量与运动分量加真实响应。
所有oracle不可部署；在有偏运动路径上加真实响应并非单调性能
上界。只有完整动作真值在这个固定库与成本下给出零regret排序。

实际唯一候选：训练868调用/24组，真实响应加原GRU、真实响应加
CV、参考真值到动作真值三种对照都0次排序改变、平均收益0、
描述性95%区间[0,0]。只改善共同运动真值有1次训练排序改变，
平均收益0.000118，区间[0,0.000355]。开发272调用/8组所有这些
对照与三个冻结模型/运动分量都没有排序改变，原GRU选择的真值
成本regret为0。因此本轮原库看不到响应预测带来的决策空间。

区间[-0.035588,0.047585]；仅加入其学习响应收益-0.023791，
区间[-0.085346,0.028214]。V17bootstrap种子固定987701，与V15
不同，故区间略不同；它不能重写V15原门。raw自身学习响应本轮
描述性收益0.011348，下界0.000215，但V15整体响应/决策比较仍
不合格，不能凭一个后验子比较晋级。

扩展库下共同运动的信息收益明显大于动作响应的收益；这不是
两个机制的已识别自然间接效应，也不能外推真实闭环捕获改善。
原实际库没有候选改变，不代表预测ADE不重要，而是此时选择集
已限制了可见收益。扩大库本身改变选择空间，必须独立消融。

## 工程复现与研究结论

首次单元测试把浮点加法再减法误当作逐位恒等，改为检查与实际
表达式相同的运算顺序；另一组错误消息正则大小写不一致已修正。
16项单元/合同测试通过（1.55s），正式数据/原成本审计没有因此
放宽。发布器在归档创建前后独立重算原数据审计、实际候选映射、
三个固定模型/中介公开推理、2,239个完整候选人口的原成本和排序。
另一个独立进程归档复核通过；V1–V17完整回归222项通过
（617.76s），包含归档独立重算测试。
