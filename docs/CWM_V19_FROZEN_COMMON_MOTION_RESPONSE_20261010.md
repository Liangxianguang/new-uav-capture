# V19：在几何候选库上独立训练共同运动与因果响应

协议先提交并推送为 `95fdcaa`；原模型仍为冻结 GRU seed745101 +
distributed-delayed DN-MPC + local CBF。本轮承接 V18 数据试验，
改变的是影子研究候选分布与训练分解，不修改原控制器或安全规则。
上一轮 V15 响应/决策门失败、V16 部分新增几何长时无效的结论保留。

## 独立新数据

32 镜像组 / 64 回合：episode 989010–989073，layout 1989010–1989041。
前 24 组训练、后 8 组开发验证；同组上/下镜像不分开，速度与传感
条件四种组合在两个分区各自均衡。未使用 V18 试采集组或保留 holdout。
wall-x=1.5 分布、目标 adaptive_branching 原规则、8 步规划时域固定。

实际首次局部调用共 1,536，训练 1,152、开发 384；无缺失延迟计划
导致的跳过。固定公开几何 pool 仅包含原/CV/径向/切向/停机命令，
队友来自实际延迟消息。两分区均通过预注册数据门，没有目标无效
探针分支。完整几何决策支持训练 815、开发 271 调用。
组等权平均响应训练 0.095577m、开发 0.084831m；>5cm 比例分别
27.842% 和 29.946%。这是动作干预标签信号，不能写成模型性能。

原控制器 64/64 回合安全捕获，采集 observer 与未观测轨迹相同；
独立公开重放完成 1,536/1,536 调用，原252历史、GRU、几何候选和
轨迹一致。本轮还保存完整逐步公开帧，训练前审计重新编码252特征，
复核每个延迟消息、候选生成、分支有效前缀/终止padding、原局部
成本及排序。局部规划器添加的 world_lower/world_upper_bounds
不在环境原observe字典，审计显式检查冻结值[-10,-10,.5]/[10,10,10]；
最初整字典相等假设已修正，采集结果未改、训练协议未放宽。

## 两阶段固定预算

三颗预分配种子989101/989102/989103，每颗种子：

1. 先用公开历史、原anchor命令和原GRU训练共同参考运动80epoch。
2. 冻结全部共同运动权重，清除梯度，排除响应优化器。
3. 各训练80epoch的原始动作响应与冻结CBF中介动作响应；两种响应
   core相同初始化和采样。最终路径=原GRU+同一个冻结共同运动+响应。

中介沿用V14公开 cbf_history 的固定中位seed976102，不更新其权重。
未来目标、CBF执行命令、分支符号、终止和valid只作标签/掩码，不
进入网络输入。共同运动始终看原anchor输入，不随中介响应改变。
响应loss只用有效非anchor配对点，终止后零padding排除。未使用
任务loss扫参、最优epoch/seed选择或预测最小成本自奖励。

所有配置的三种子最终epoch都报告，选择各自ADE中位种子。响应
必须优于零响应，完整原成本决策收益区间下界必须大于0，并独立
对照自身冻结共同运动、CV和中位纯运动配置；中介还需优于raw。
另外报告原实际库到几何库的库扩展收益，不归入响应模型增益。
两次独立完整训练需核对权重、优化器、RNG、损失历史和公开预测。

## 固定开发结果：两种响应模型仍未晋级

| 条件（训练配置取三种子中位数） | 组等权 ADE/m | 配对响应误差/m |
| --- | ---: | ---: |
| 原 GRU / 零响应 | 0.658321 | 0.084831 |
| CV / 零响应 | 0.350314 | 0.084831 |
| 冻结共同运动 / 零响应 | 0.308292 | 0.084831 |
| 同一共同运动 + raw 响应 | 0.298425 | 0.085681 |
| 同一共同运动 + 中介响应 | 0.300220 | 0.087103 |

三种子完整结果均保存，不用最佳 seed 代替预注册中位选择。
motion_only/raw/mediated 的 ADE 中位 seed 均为 989103；其对应响应误差
分别为 0.084831/0.090403/0.088364m。表中响应误差中位数不必来自
同一个 ADE 中位 seed。raw seed989101 的响应误差0.078856m优于零响应，
但其余两颗为0.085681/0.090403m，不能事后挑它声称整体通过。

两种响应配置都通过了每 seed ADE 对原 GRU 及中位 ADE 对 CV 的门；
中位响应误差对零响应、决策收益门均失败，中介对 raw 的门也失败。
271 个完整开发调用、8 组的原完整成本对照（ADE 中位 seed989103）：

| 响应配置/对照 | 组平均 regret 收益 | 描述性95%组区间 |
| --- | ---: | --- |
| raw 对自身冻结共同运动 | -0.004102 | [-0.040790,0.029920] |
| raw 对 CV | 0.054590 | [-0.011599,0.133731] |
| 中介对自身冻结共同运动 | 0.035365 | [-0.045629,0.129387] |
| 中介对 CV | 0.094057 | [-0.021099,0.239200] |
| 中介对 raw | 0.039467 | [-0.014784,0.111518] |

本次三个配置恰好选择同一 seed，故对自身运动与选中 motion_only 的
收益相同。两次完整训练的权重/优化器/RNG/损失历史相同，公开中介
重载、预测逐位一致。该结果支持运动校准的预测价值，但不支持
响应模块稳定提高决策，不能用整体 ADE 改善代替因果增量验收。
库扩展的原 GRU/CV 对照另外保留于数据原成本记录及分区汇总中。
