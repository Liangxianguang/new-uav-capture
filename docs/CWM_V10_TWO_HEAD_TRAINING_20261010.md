通过。共同运动校准有明确预测收益；动作响应的稳定增量收益尚未
证明，预设开发门未通过。原 GRU + DN-MPC + 经验型 local CBF
保留，增强控制关闭。本文不是原八个 Level 的新覆盖率报告。

收集实际局部调用的公开历史、收到的延迟队友状态/计划，以及
原局部选择组成的参考命令，而不是继续仅用最终联合计划训练。

未采集、未使用。保持既有 S4 target规则、wall center1.5m、速度
及传感条件的已资格化变化范围，不改原 Level、权重或安全裕度。

共1280个首轮实际局部调用；512个缺少完整三队友延迟计划而跳过，
768个可学习调用，576训练、192开发。候选库冻结为V9规则和V7
中位模型生成，与V10新权重和未来 truth 无关。共同有效非参考
响应点训练8487、开发3065，平均响应幅度分别0.025566/0.014010m，

64个原策略回合均安全捕获，无原 target-invalid。每回合带/不带
采集的全部保存轨迹数组相同、七项结果字段一致。另独立运行64

## 实际训练内容

三个架构、各3个种子、80固定epoch、相同Adam/batch/学习率：
独立训练的仅运动校准、普通双头、图池化双头。普通与结构化总
参数32736/32960，相差0.68%。仅运动模型保持普通架构总预算，
响应头冻结为零，可训练参数31176；这项消融的训练容量差异明确
披露。新增历史编码器是可选模块自己的GRU，不是原GRU微调。

共同运动头学习参考命令下的目标轨迹校准；响应头学习同状态、
共同噪声下候选减参考的配对效应。分别masked MSE，按调用的
逆组数量加权；不使用终止后标签。只用训练历史做归一化。两个
残差各限制2.5m/坐标，但这不是速度、动力学或安全证书。

参考命令的**响应**严格为零，但启用运动头时参考**预测**会改变；
只有关闭整个增强模块才返回原模型。没有以“参考响应为零”代替
入口级关闭/失败回退证明。当前仍为离线/影子研究，不启用新控制。
没有私有 branch labels、真值目标或未来路由进入网络。图池化与
普通模型都接受配对干预监督，比较的是结构选择，不是证明只有
图池化才有因果性，也不声称已识别可迁移的 SCM。

## 固定局部库的探索性决策归因

在已看过的开发数据上进一步检查同一冻结局部库，不使用holdout。
192调用中136个有全部候选/参考的完整8步支持；56个共同排除。
重载固定中位模型，以原完整局部目标/风险聚合评分。真实路径仅
作离线label条件，预测均为raw容器，不是动力学投影或性能上界。

| 同库信息 | 平均诊断regret | 对同库GRU的组等权gain |
| --- | ---: | ---: |
| 原GRU | 0.840215 | 0 |
| 常速度 | 0.170232 | +0.669461 |
| 独立训练仅运动 | 0.156391 | +0.687217 |
| 普通双头 | 0.148057 | +0.696304 |
| 结构化双头 | 0.124827 | +0.719431 |
| 真实参考运动 | 0.054030 | +0.786248 |
| 完整action-specific truth | 0 | +0.843375 |

上述是诊断成本，不是实际捕获回报。结构化双头相对其自身运动
分量，加响应改变9个选择，gain+0.054013，描述性95%组区间
[-0.006766,0.135907]；普通改变5个选择，gain+0.000430，区间
[-0.012459,0.014486]。这是不稳定的探索信号，不能宣称稳定因果
收益。结构化双头相对常速度gain+0.049970，区间
[-0.030570,0.149789]；相对独立仅运动gain+0.032214，区间也跨零。

结构化响应的点误差虽更大，却可能在少数决策关键窗口更有用，
说明平均MSE/ADE与任务价值并不完全一致。但当前证据既不足以
覆盖失败门，也不足以证明闭环、安全或对常速度/仅运动的稳定
优势。未评估新模型自生成候选库、全部顺序迭代或反馈控制。
