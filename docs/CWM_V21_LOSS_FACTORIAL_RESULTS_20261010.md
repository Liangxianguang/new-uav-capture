# V21：响应预测改善，但决策验收失败

## 结论与适用范围

两次独立完整训练均结束，固定五配置、三种子、最终80epoch，不挑选最佳
seed/epoch，不改预先指定的主实验 `raw_point_l2`。L2两配置的开发响应误差
中位数相对零响应改善16.18%–16.89%，通过响应误差门；四种响应配置都没有
通过整体ADE对恒速预测和完整原成本决策收益门。主实验研究资格失败，
因果增强控制器仍关闭。不能把响应预测改善写成围捕效率或捕获率提升。

本报告的数据是已用于验收的开发集，不是未触碰holdout。下面的原控制器
64/64安全捕获不是增强模型成绩，也不是原8Level的增强闭环覆盖结论。
原始dirty checkout不修改、不暂存、不停作业；研究在独立分支完成。

## 为什么不能仅看平均响应误差

全开发点约71.29%的真响应<=5cm。L2大幅减少弱响应段误报：数值零响应点
上预测>5cm的比例，MSE约7.9%–9.5%，L2约1.38%–2.88%。但>20cm强响应
段误差在三个seed上均大于匹配MSE；该段真响应条件均值约0.642704m。
因此这是弱响应改善与强响应损失之间的取舍，不是所有交互都预测更准。
共同运动模型train ADE约0.134–0.140m，dev约0.354–0.413m，仍有泛化差距。
“共同运动泛化/强响应/排序何者主导失败”尚未被实验分离，不能直接下定论。
