# P1–P4：目标响应世界模型首轮训练审计

日期：2026-10-09。结论：**NO-GO，继续使用原 DN-MPC + local CBF**。

本报告记录真实完成的离线试验，不是增强控制器的成功报告。原权重、原源码、
原任务合同均未修改；guarded 接口拒绝启用。原版完整256场重放通过，见P0报告。

## 数据与训练

仅使用原train池的36场Level5/6场景，共24个独立镜像组；在第4、12、20步
采集108个同状态窗口。每个窗口包括原规划、左右各1.5m/s偏置、半速四个分支，
预测8步（0.8秒），历史8步。各分支保留原CBF及执行动力学；终止后不再仿真。
公共252维编码、相对状态、提议动作是输入；目标真值仅作标签。

按镜像组划分72/18/18个训练/校准/内部验证窗口。三者均来自原train池，
不是正式泛化测试，也不是Level1–8覆盖。没有使用holdout调参。
普通动作条件GRU（37,272参数）与结构化响应GRU（36,560参数）使用同一数据、
相同预算和配对响应损失，种子101/202/303，固定40epoch末轮权重，CPU单线程。
结构化网络为自主运动残差与逐机压力响应聚合，不等同已识别的SCM。

## 内部验证结果

下面为三个种子的指标算术平均；恒速和零响应是无需训练的诊断参照。

| 方法 | 轨迹ADE（m，越低越好） | 末步FDE（m） | 配对响应误差（m） |
| --- | ---: | ---: | ---: |
| 普通动作条件GRU | 1.564563 | 1.694945 | 0.076001 |
| 结构化响应GRU | 1.780907 | 1.854301 | 0.020623 |
| 恒速预测 | 0.190445 | 未统计 | 未统计 |
| 不预测动作响应差异 | 不适用 | 不适用 | 0.000136 |

全体有效配对点的真实目标位置响应均值仅0.000169m，p95为0.000125m，
超过0.1m的比例为0。结构化模型虽比普通模型的响应误差小，但仍远弱于零响应；
两者轨迹预测都弱于恒速。该结果不足以支持因果预测或闭环收益，不能直接加大训练。
配对共同随机流只是模拟器干预耦合，并未证明全部外生扰动可识别。

## 复现与旁路验证

- 六个保存权重可用`torch.load(weights_only=True)`重载，内部验证预测一致，最大误差0。
- 从发布ZIP独立解压源码和数据后重训六个模型：模型权重、保存预测的原始字节、
  每轮loss历史及验证指标全部一致。再次核验原9项provenance哈希，均未改变。
- 全部选中镜像组与原完整validation场景组的交集为0。
- 四个历史回归场景的shadow检查共121次调用，零异常，原动作、完整轨迹数值和物理结果不变。
- 旁路额外耗时p50/p95/p99为2.753/4.864/5.791ms，仅是本机测量，不是实时保证。
- 九项单元测试通过，包括off不调用模型、shadow异常回退、输入隔离及guarded拒绝。

## 下一阶段

第一项train-only数据诊断已完成：左右施压的实际执行速度差均值为1.41/1.44m/s，
半速分支为1.62m/s，说明差异并未简单被CBF完全抹掉。然而采样时最近无人机
距离公共目标参考位置均值7.54m，响应的中位数均为0。冻结目标源码包含8步重规划
间隔及最小模式保持逻辑；需要记录实际决策与距离，不能仅凭源码认定根因。

先在原train池诊断：提议动作是否经过CBF/执行器后仍有差异；无人机与目标距离、
目标决策触发条件及保持时间是否使早期0.8秒窗口缺乏可学习响应；改变采样时机或
压力几何是否产生稳定信号。保留相同状态对照，不改目标规则、不放松安全合同。
如果找到有效响应，再预先冻结新数据与训练协议；现网络已含恒速加残差，需约束
残差初始化、幅值和学习，而不是把恒速残差本身当作新设计。
进行同预算消融及新鲜内部验证；若没有信号，停止这一增强路线并保留原控制器。
离线预测通过后还必须单独验收闭环和Level1–8覆盖；本轮未做此类声明。
