# 新 S4 场景：学到响应，但尚未证明围捕收益

日期：2026-10-10。阶段：V7 已完成配对响应训练及独立重训；V8 完成
固定动作探针的决策价值诊断。因果增强未启用，仍使用原 DN-MPC +
经验型 local CBF。本文不是原八个 Level 的新覆盖率报告。

## 最新结论

新场景资格检查、数据采集和六个预测器的训练已经完成。结构化响应
模型相对于不预测动作响应，开发集配对响应误差改善约25.13%；但比
参数量、训练预算相匹配的普通响应模型差2.38%，未满足预先规定的
至少5%优势。因此“学到响应”成立，“因果结构优于普通网络”不成立。
整体目标轨迹预测与闭环围捕提升也未证明，不能因为有创新概念就
替换原模型。这里只做了配对干预响应学习，不声称已识别真实 SCM。

V8 将原 GRU、普通/结构化响应预测、常速度、真实响应、真实参考
运动等九种信息输入放到原完整 MPC 目标下比较。此前 ADE 分析
提示共同运动误差较大，但本次发现：即使提供真实运动或真实响应，
在固定八探针集合中也没有改变最优选择。因而目前证据不足以支持
直接加训练轮数，或仅为降低 ADE 就训练共同运动校准头。

## 实验边界

只用 V7 已检查过的8组/16个开发场景、80个窗口；未使用保留的
独立 holdout 或原 Level 测试数据。模型固定为开发误差排序中位
seed：普通967101、结构化967102，不选择最优 seed。

每个窗口的八组8步动作来自已有原动作/压力/制动探针。保持原
DN-MPC horizon、目标权重、风险聚合、延迟消息和 CBF 不变，复制
原计划后的 planner 状态，使用完整 `_team_scenario_costs` 评分。
没有用距离代价替代原目标，也没有在线使用真实未来轨迹。

要求所有八个探针均有完整8步真实支持；69个窗口可排名，11个
终止截断窗口对所有方法同时排除，不补齐终止后的标签或成本。
置信区间是已检查开发集的描述性按组 bootstrap，不是独立检验。
“诊断 regret”以 action-specific truth 下的同一 MPC 代价定义，
不是实际围捕回报，更不是真实控制性能上界。

常速度按组等权的诊断 gain 为 -1.660132，描述性95%区间
[-4.980395,0]。它在先前开发集 all-branch ADE 中优于 GRU，但在
这里两次改变的选择都更差。这是“预测更准不等于决策更好”的
具体反例，不意味着常速度在所有任务都更差。

运动校准与给定准确运动的动作响应，两项探索性 research signal
均为 false。V7 训练资格门未被覆盖；任何 truth 条件都是离线
标签诊断，不具备在线部署资格或动力学安全认证。

## 下一步必须测真正的分布式局部候选

这个 No-Go 只针对现有八个探针，不是证明因果模型永远无用。
实际原 planner 的局部候选也依赖预测；固定探针的完整团队评分
并不等于顺序分布式优化器的选择。已检查冻结代码：

1. `plan` 每次 agent/iteration 先通过 `_known_peer_messages`
   取该 agent 此时可获得的延迟消息，再生成局部候选。
2. `_local_candidate_sequences` 用预测目标路径决定拦截者与
   编队偏移，产生本地动作序列。新预测不仅可能改变评分，也可能
   改变这个候选库。
3. `_select_local_sequence` 对 `_local_scenario_cost_matrix` 做
   原风险聚合，更新本 agent 序列，再广播/接收消息。

因此下一阶段的验收对象应是实际局部调用，不能继续把八探针
无变化当作通用结论。建议先做 default-off 的 shadow 适配器：
采集实际候选及其当时的已知消息，将固定模型用于影子预测/评分，
不接管实际动作。局部命令联合上下文只能使用对应调用的已知
peer sequences，不能偷换为集中式当前真实队友计划。模型训练于
八探针，对局部候选可能分布外，需要明确记录这一限制。

如果影子结果显示决策差异，再对候选进行原 CBF + 共同噪声的
克隆分支验证，区分“改了选择”和“改善了闭环结果”；终止、
碰撞、边界及缺少消息都要如实统计，不能补标签。只有建立价值
证据后才选择共同运动头、响应头或更长时域的下一训练假设。
不改原通信语义、目标规则、安全裕度或现有预测权重。

最后再固定新的训练/评估设计并使用未触碰的 holdout；之后仍需
原8个 Level 的配对回归、多种新场景转移、安全与延迟检查。
关闭增强应不加载新权重、不多调用原预测器、不消耗额外 RNG，
失效时回到原策略。完整 default-off/失败回退的入口级重放仍是
未完成的后续任务，不能用“参考动作响应为零”代替这个证明。
