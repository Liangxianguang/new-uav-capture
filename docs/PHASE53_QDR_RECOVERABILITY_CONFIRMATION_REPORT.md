# Phase 53 QDR Recoverability-Window Confirmation Report

> Status: frozen validation-confirmation result. The fresh manifest and the
> two-step window were fixed before this evaluation. No locked-test data or
> locked-test tuning was used.

## 1. Objective

Phase 52 showed that applying a calibrated empirical execution tube over the
full prediction horizon protects geometric clearance but destroys liveness
under an immutable delayed-command queue. Phase 53 therefore limits the tube
to the first two immediate controllable suffix steps and leaves the remaining
suffix to the next replanning cycle.

The confirmation compares this recoverability-window candidate with nominal
QDR on exactly the same scenes, predictor seeds, sampling seed, planner,
execution contract and local CBF layer.

## 2. Reproducible protocol

```text

episodes: 100 per arm and predictor seed; 50 mirror groups

predictor: frozen GRU both checkpoints, checkpoint source
candidate samples / sampling steps: 1 / 8
prediction refresh: every control step
safety layer: local CBF
split: validation_confirmation
bootstrap: 10,000 paired samples, seed 20260913
```

Both arms use delay `4`, immutable pending-command authority, command-noise
standard deviation `0.08 m/s` clipped at `3 sigma`, nominal sensing and
communication, and zero tracking time constant/drag. The windowed arm uses
the independently calibrated Phase 52 randomized-stress artifact with frozen
multiplier `2.0342518477112503`; only the first `2` suffix steps receive the
tube radius. UAKR and RNIC are disabled.

The confirmation configuration is
`configs/phase53_qdr_recoverability_confirmation.yaml`. The evaluator records
the effective configuration, source hashes, manifest hash, episode/step
JSONL and TensorBoard events for every seed.

## 4. QDR liveness gate

The pre-registered gate is:

```text
candidate timeout rate                         <= 5%
timeout delta versus paired nominal reference <= 5 percentage points
maximum exhaustion streak                     <= 24 control steps
```

The machine-readable result is
`results/phase53_qdr_recoverability_confirmation_gate.json`, generated by
`scripts/evaluate_qdr_liveness_gate.py` with candidate group `windowed`.

| Check | Observed | Limit | Decision |
| --- | ---: | ---: | --- |
| Windowed timeout rate | 0.33% | 5.00% | PASS |
| Timeout delta vs nominal QDR | 0.00 pp | 5.00 pp | PASS |
| Maximum exhaustion streak | 30 steps | 24 steps | **FAIL** |

Overall status: **No-Go for promotion of the two-step windowed tube**. This is
not a failure of the QDR implementation itself; it shows that the current
frozen empirical margin is not yet a reliable recoverability mechanism under
the stated gate. Nominal QDR remains the reference candidate for the fixed
delay-4 execution contract from Phase 48, subject to its documented scope.
