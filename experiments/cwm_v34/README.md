# V34 fresh four-geometry prefix data (untrained)

This stage implements complete streaming data collection and an independent
native replay auditor, not model efficacy, causal identification or promotion.
The original GRU745101/252 encoder, distributed-delayed DN-MPC and local CBF
margin0.35 remain unchanged. Enhancement is off; private labels are never
public proposal or predictor inputs. V28 failed gates are not superseded.

`data_protocol.json` fixes64 layout/noise families (48TRAIN/16development),
two mirrors and four geometry variants per family, hence512episodes but only
64 independent groups. All mirrors/axes of a family share one split. Matching
axes share original episode/controller sampling identities; artifact identities
are unique. Target rules are unchanged; route errors stop the full population
without replacing, filtering or selecting favorable cases.

The original public bounded24/two-round proposal library is retained first.
For EVERY nonanchor base candidate, k=2 and5 probes replace only its own-agent
suffix with public anchor commands, leaving received peer plans unchanged.
Exact dedup retains all mapping aliases. ALL public candidates/probes are
frozen before ANY private labels. Native branch prefixes must match all seven
physical arrays by dtype, shape and bytes, including terminal padding.

Extra probes are physical training support, NOT a larger scoring/deployment
library. Full original-cost ranking compares the unchanged base library only.
No learned output controls the collection trajectory. Each native observed
episode is compared with an untapped original episode's numeric trajectory,
plan, CBF command and outcomes. Arrays stream to disk; scalar support records
are retained in RAM. Other live training processes must not be interrupted.

## Execution

Publish the EXACT source/protocol Git HEAD first; the collector verifies the
official GitHub branch via existing Git credentials and every used V34 source
byte against that commit. Use the original Python dependency environment.
Both output paths must be NEW and nonexistent:

```powershell
python experiments/cwm_v34/collect_prefix_data.py --output <NEW_data_directory>
python experiments/cwm_v34/audit_prefix_data.py --data <complete_data_directory> --output <NEW_audit_directory>
```

Run the second command only after actual first-process exit0, the complete
512episode summary and ALL original data gates pass. Partial output, logs,
passing synthetic tests or missing-peer imputation cannot authorize training.
Never edit the actual source/protocol closure while collection/audit runs.

The independent auditor uses separate planner interception/public prefix
reconstruction, reruns ALL native branches and original full costs, verifies
all trajectories/plans/CBF against observed AND untapped evidence, recomputes
whole-population support and rejects evidence/source mutation. Its eventual
training authorization is ONLY a data prerequisite, not efficacy approval.
