# V40 source/archive-bound V36 scorer preload

Implementation only; no native V34 scientific weights or V38 qualified archive
exist yet. This package cannot enable original production control, run a UAV
episode, generate scenes, train, inspect holdout or authorize V39's full runner.
Original controller and all previously frozen scientific sources are unchanged.

`research_loader.load_bundle` defaults to `mode='off'`; off/refused returns an
empty unauthorized bundle without resolving paths, reading protocols or creating
a model/cache. Only explicit `research_prepare` can preload, BEFORE a timed
planner, from complete V38 archive plus its native extracted replay certificate.
Cache must be new. Exceptions retain failed cache evidence and return no bundle.

The complete archive length/hash/CRC/member inventory and native replay flags are
verified; all source/dependency bytes must match the current corresponding Git
checkout. V38's full curated inventory checks native audited data and both full
training runs, actual preregistered Git history and checkpoint/prediction/cache
identities. Original independent-reload SHA, qualification and release contract
must match the native archive certificate. The certificate is local audited
provenance, not a cryptographic signature or substitute for real V38 replay.

Failed fixed prefix primary returns unauthorized before any selected neural
checkpoint or proposer reconstruction. A passed primary requires every unchanged
strict offline gate true; all nine final models/all3seeds remain mandatory.
Each configuration's fixed final80 BASE ADE-median seed is independently derived,
never chosen by decision gain. Preload restores selected motion/full-query/prefix
model/Adam/sampler/Torch RNG through unchanged V37 reconstruction without update,
verifies original data/audit/source/normalizer/weights/cache provenance and exact
per-seed frozen common stage, with caller RNG preserved. Failed full-query may
only be a comparator under an independently qualified prefix primary, not a
replacement primary or deployment candidate.

Models receive only six original public arrays, original TRAIN-only normalization
and fixed float32 neural/float64 target-path precision. Runtime input boundary
requires at most24 BASE proposals, original shape/speed/finite contracts and
unchanged float32 prefix-anchor identities. The existing OptionalResponseAdapter
verifies target forecast decomposition/common independence/anchor zero and
refuses malformed forecasts. Models/proposer are preloaded, with no checkpoint
IO in a later planner. Target paths are NOT UAV commands. Caller RNG is preserved.

Archive/certificate/current/extracted evidence are checked again after loading;
authorization is assigned last. Adapters stay shadow-only, deployment false.
The returned prefix bundle is a distinct type, NOT accepted by old V29 active
selector. `legacy_l2_control_loaded=false` and `full_v39_runner_ready=false`
remain explicit: the separately bound old L2 loader/new sequential selector/
paired8method original1280+fresh64 runner, qualified active faults, complete
native result replay/archive and sealed holdout confirmation are still required.
No legacy failed checkpoint is loaded or enabled by this package.

Tests use forged synthetic certificates/mock archive authorities and tiny toy
80epoch checkpoints. They exercise fail-closed provenance/order/public inference
and real toy Adam/RNG restoration only, not native archive loading, causality,
new model training, real control/fault fallback, capture/safety/latency or deploy.
Do not present synthetic authorized bundles as scientific qualification.
