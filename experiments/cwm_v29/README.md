# V29: independently gated RESEARCH sequential local selector

This is not a trained model or demonstrated capture improvement. V28 data audit,
two complete fixed-budget trainings and full archive replay must finish first.
Only an artifact-bound real replay certificate and unchanged passing V28 primary
offline qualification authorize research selection. Failed V23 never qualifies.
No deployment gate is relaxed: research evaluation is a separate, isolated route
to MEASURE the still-pending online/capture/safety/latency requirements.

`research_bundle.load_bundle` reconstructs only the fixed final ADE-median V28
models AFTER verifying the complete archive/certificate/current source binding.
All IO/reconstruction is before the original timed planner. An initialized model
used in a unit test is not a real80epoch trained result. Local certificates are
audited provenance, not cryptographic signatures. Off/refusal creates no bundle
or optional context. A failed primary returns unauthorized, before any checkpoint
reconstruction, rather than replacing it with a better control/seed.

`local_selector.select_research` preserves the original anchor, received peer
context and full original K1 local cost. The bounded shared proposal library is
generated by the unchanged failed V23 public proposer for ALL scorer controls,
so the new scorer does not silently get a different library. Target paths are
never UAV commands. First-index original argmin is retained. Optional controls:
original GRU, public CV, primary's own frozen common motion, independently selected
motion-only control, L2 response, ranking response. Scoring networks receive only
the six public arrays; costs/labels/truth never enter forward. The selected return
cost row and team metadata are evaluated against ORIGINAL scenarios, not replaced
by optimistic learned costs. CBF, margins, target rules and communication remain
unchanged. Deployment eligibility is always false here.

`SequentialResearchEntry` installs EXACT parent runtime/planner for off/refusal.
An authorized isolated research run captures the actual original252 frame before
planning, rebuilds inputs with newly received delayed plans for EVERY sequential
best-response call and records evidence after plan. All expansion/inference/full
cost scoring and capture-copy time count in the unchanged original plan timeout.
No time subtraction, fake clock or deadline relaxation is permitted. Log IO is
outside timed plan but later end-to-end latency evaluation MUST include it.
Runtime failures discard expansion and disable further research, returning the
original local selection/costs. Timing effects or earlier changed actions cannot
be undone; exact whole-episode failure equivalence requires real qualified-model
fault regression and is NOT proved by synthetic local tests.

Current CLI deliberately exposes only disabled/refused historical regression:

```powershell
python -m pytest experiments/cwm_v29 -q
python experiments/cwm_v29/sequential_entry.py --fallback-regression --output results/cwm_v29/NEW_OFF_REGRESSION
python experiments/cwm_v29/release_fallback_regression.py --primary results/cwm_v29/FIRST --repeated results/cwm_v29/SECOND --artifact experiments/cwm_v29/artifacts/NEW_REGRESSION.zip --replay-output results/cwm_v29/NEW_ARCHIVE_REPLAY
python experiments/cwm_v29/release_fallback_regression.py --verify experiments/cwm_v29/artifacts/NEW_REGRESSION.zip --replay-output results/cwm_v29/NEW_INDEPENDENT_REPLAY
```

Two historical records are unchanged V26 regression IDs, NOT new development
scenes or reserved holdout. Regression release checks both independent runs and
all original trajectories/plans/CBF commands, then re-runs the REAL original entry
in a fresh child process against the ZIP evidence. It does not run an active
model, actual trained-model faults, full Levels or latency qualification. Active
experiment CLI/scenes/protocol, real qualified model faults, reserved holdout,
complete original Levels/new scenes paired closed-loop evaluation and a complete
result publication remain required. Do not automatically start active evaluation
or promote a model when only these regressions pass. Original fallback stays
default; local CBF is empirical filtering, not a new formal safety proof.
